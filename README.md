# Interview Ready

An eleven-episode audio revision series for senior Databricks interviews (partner data architect and Databricks Senior Forward Deployed Engineer), about 113 minutes.

- Listen on the web: https://tripsankur.github.io/interview-ready/
- Podcast feed: https://tripsankur.github.io/interview-ready/feed.xml (in Pocket Casts: Search, paste the address, Subscribe)

Narration is synthesised with the open-source Kokoro text-to-speech model. Transcripts are in `transcripts/`.
